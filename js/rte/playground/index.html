      Notes
      

        The first surface is the explicit integration: its commands and toolbar
        markup are listed in this page for inspection, while their behavior
        comes from the production modules. The lower prototype is the
        convention integration and wires itself from one import plus CSS.
        Invalid nested structures are built with DOM methods because the HTML
        parser repairs some of them immediately. “Parse and apply HTML” is
        deliberately available to compare parser behavior with RTE behavior.
        Place a selection inside the editor before stepping to observe mapped
        range boundaries. Dispatch sends a cancelable beforeinput
        and, unless a command replaced it, the following input.
        Input types without a command run cleanup policies only; they do not
        imitate the browser's native DOM mutation, so edit or apply HTML first.
        The prototype toolbar lists every ready control, so the order in
        --u2-rte-toolbar is the order shown. Undo and redo also
        work from Ctrl/Command+Z and +Y; the readout under the surface reports
        how many entries the history holds and where it stands, which makes the
        grouping visible: continuous typing coalesces, while each command,
        paste, and drop is its own step. List controls consult the content
        model, so they disable themselves in a host that does not allow them.
        The </> control opens the HTML source of this surface
        in a modal dialog, positioned at the caret. Applying it parses the text
        through the sanitizer, never through innerHTML, and lands
        as one undo step. Its text area is wrapped in <u2-code>,
        so the source is syntax highlighted once that element has loaded.
        The link control opens a contextual form at the selection: a caret
        inside a link edits that whole link, a selection creates one. Its
        address is a plain text field, so relative paths, fragments, and
        application schemes are accepted and the sanitizer decides what
        survives.
        Clicking the image selects it and frames it with corner handles. The
        drag moves the frame only and the size is written once when it is
        released, so a resize is one undo step rather than a trail of them; the
        corners keep the proportion. Putting the caret in a table cell brings up handles on the table itself:
        rows down its left edge, columns along its top, lined up with the cell
        you are in. They name no tag — sections, rows and cells come from the
        content model's default child — and a cell spanning several columns
        makes the counted actions unavailable rather than shifting the wrong
        cells. Inserting a table stays a toolbar action, because it applies
        where no table is.
        Remove formatting walks a ladder that never runs out: foreign styles,
        presentational attributes and classes, then the declared content
        classes, the remaining semantic inline elements, and finally the
        structure itself — lists, tables, quotes and headings all reduce to
        plain blocks. Every control's key works whether or not it is listed in
        --u2-rte-toolbar; hover a control to see its shortcut.
        The style list offers exactly the names in
        --u2-rte-classes. That one declaration is also what the
        sanitizer keeps from pasted HTML and what remove-format leaves alone, so
        a class the host knows is never offered without being allowed, and never
        cleaned away as foreign.
        Bold recognizes both <strong> and <b>,
        creates canonical <strong>, and unwraps either form on
        removal. The class-mark buttons reuse a fully selected inline element;
        otherwise they create a <span class="x">.
