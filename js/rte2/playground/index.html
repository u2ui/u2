      Notes
      

        The first surface is the explicit integration: its commands and toolbar
        markup are listed in this page for inspection, while their behavior
        comes from the production modules. The lower prototype is the
        convention integration and wires itself from one import plus CSS.
        Invalid nested structures are built with DOM methods because the HTML
        parser repairs some of them immediately. “Parse and apply HTML” is
        deliberately available to compare parser behavior with RTE2 behavior.
        Place a selection inside the editor before stepping to observe mapped
        range boundaries. Dispatch sends a cancelable beforeinput
        and, unless a command replaced it, the following input.
        Input types without a command run cleanup policies only; they do not
        imitate the browser's native DOM mutation, so edit or apply HTML first.
        Bold recognizes both <strong> and <b>,
        creates canonical <strong>, and unwraps either form on
        removal. The class-mark buttons reuse a fully selected inline element;
        otherwise they create a <span class="x">.
